Plug & play setup

Install with npm

Install the package, import the stylesheet, and mount the player. You do not need to copy player source files into your project.

1 · Install

npm install @workrcs/universal-player

2 · Vanilla JS / TypeScript

import { createPlayer } from '@workrcs/universal-player';
import '@workrcs/universal-player/style.css';

const player = createPlayer('#video-player', {
  source: 'https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4',
  theme: 'system',       // 'dark' | 'light' | 'system'
  glass: true,
  accentColor: 'rgb(54, 214, 176)',
  controlsStyle: 'standard',
});

player.setTheme('dark');
player.setGlassEffect(true);
player.setControlsStyle('compact');
player.setFeatures({ stats: false, miniPlayer: false });

// Later, when the component unmounts:
// player.destroy();

3 · Add a mount point

<div id="video-player"></div>
React

Create the player in useEffect and call destroy() in cleanup.

Vue / Svelte

Mount in the component's mounted lifecycle and destroy on unmount.

Quality & streams

Adaptive HLS/DASH quality options depend on renditions provided by the stream. A plain MP4 generally has one encoded quality.

Note: browser codec support, CORS, provider embed rules, DRM and authentication can limit playback. “Any URL” cannot mean every webpage or protected video is playable; use direct media URLs or supported provider links.
